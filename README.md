# 企业级CV分析平台

一个支持**图片批量处理、视频完整分析、实时摄像头监控**的CV工具，集成超分增强、深度估计、目标检测、行为识别等能力，界面友好、稳定性高，适用于快速CV分析场景。


## 📋 功能清单
| 功能模块       | 核心能力                                                                 |
|----------------|--------------------------------------------------------------------------|
| **图片处理**   | 批量上传/分析、超分增强、深度估计、目标检测、行为识别、结果导出           |
| **视频处理**   | 视频上传、完整帧分析、在线预览、结果下载                                 |
| **实时摄像头** | WebSocket低延迟推流、实时分析、一键启停                                 |
| **配置优化**   | 超分倍数/检测置信度/功能开关（侧边栏集中配置）                           |


## 🚀 快速启动
### 1. 环境依赖
- Python 3.8+
- 虚拟环境（推荐Anaconda）
- 依赖包安装：
  ```bash
  # 激活虚拟环境后执行
  pip install fastapi uvicorn ultralytics opencv-python streamlit requests websockets pillow pandas matplotlib
  ```


### 2. 启动步骤
#### 步骤1：启动后端服务
```bash
# 进入项目目录
cd 项目根路径
# 激活虚拟环境（Anaconda）
conda activate cv_env
# 启动后端
python enterprise_cv_service_optimise_v3.py
```


#### 步骤2：启动前端页面
```bash
# 新打开一个终端，激活虚拟环境
conda activate cv_env
# 进入项目目录
cd 项目根路径
# 启动前端
streamlit run cv_streamlit_frontend_optimise_v3.py
```


#### 步骤3：使用平台
打开浏览器访问：`http://localhost:8501`


## 🛠️ 使用指南
### 1. 图片上传分析
- 点击「Browse files」可**批量上传**JPG/PNG图片
- 侧边栏配置：
  - 超分放大倍数：1-4倍（倍数越高，处理越慢）
  - 检测置信度：0.1-1.0（数值越高，检测越严格）
  - 功能开关：按需启用「超分增强」「深度估计」
- 处理完成后，可点击「导出结果」下载分析后的图片


### 2. 视频上传分析
- 上传MP4/AVI/MOV格式视频
- 点击「开始处理视频」后，等待进度完成
- 处理完成后，可在线预览视频，或点击「下载处理后视频」保存


### 3. 实时摄像头分析
- 点击「启动摄像头」，实时分析摄像头画面
- 点击「停止摄像头」可关闭分析
- 支持超分/深度估计（需提前在侧边栏开启）


## ⚙️ 技术栈
- **后端**：FastAPI + Uvicorn（高性能API服务）
- **CV能力**：Ultralytics YOLOv8（目标检测）、OpenCV（超分/深度估计/图像处理）
- **前端**：Streamlit（快速构建交互界面）
- **通信**：WebSocket（摄像头实时推流）、HTTP（图片/视频接口）


## 📝 注意事项
1. 视频处理耗时与视频长度/分辨率正相关，建议先测试短视频
2. 超分增强/深度估计会增加处理时间，低配设备建议关闭
3. 临时文件会每小时自动清理，无需手动删除
4. 若摄像头无法启动，检查是否有其他程序占用摄像头
